> **不是** XBuilder Publish；也**不是**等 x.qiniu.com 开放手机。

### 3.0 托管推荐排序（优先：国内可访问、微信内稳、团队上手快）

| 序 | 方案 | 推荐理由 |

### 3.2 七牛 Kodo 最小路径（给非产研）

1. 登录七牛控制台 → 对象存储 Kodo → 新建空间（选就近区域）。  
2. 上传 1024 交付的手机网页目录（保证根目录有可打开的入口页，如 `index.html`）。  
3. **联调：** 可用空间**测试域名**（约 30 天，勿当正式投放链）微信内点开验收。  
4. **正式：** 绑定**已备案**自定义 CDN/源站域名 → 配 CNAME → 托管 SSL → 强制 HTTPS。  
5. 把最终 URL 回填本文所有 `（待 1024 提供手机网页 URL）`，再生成二维码。  
6. 参考：https://developer.qiniu.com/kodo/8527/kodo-domain-name-management  

### 3.3 备案与微信打开（所有国内方案共用）

- 中国内地托管 + 自定义域名对外提供网站服务 → **须 ICP 备案**（工信部）。  
- 未备案或备案异常：云厂商可能冻结域名；微信内大量分享未备案域可能「无法打开 / 停止访问」。  
- 规范：https://weixin.qq.com/agreement/weixin_external_links_content_management_specification

## 6. 小程序 web-view 包一层是否可行

### 结论

**可行性：有条件可行；前提改为「自托管手机网页的备案域名」，不再使用 x.qiniu.com。**  
仍**不是今天路径**；适合已有企业主体小程序、需要小程序码分发时再上。

### 硬性条件（官方）

| 条件 | 要求 |
| --- | --- |
| 主体 | **非个人**小程序；个人主体不支持 web-view / 业务域名 |
| 业务域名 | HTTPS；ICP 备案；**域名根目录**放置校验文件；管理员扫码确认 |
| 内容 | 内嵌页须备案；与小程序类目一致；不得用 web-view 规避规则 |
| 小游戏账号 | 业务域名/web-view **不对小游戏账号开放** |

来源：  
https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html  
https://developers.weixin.qq.com/miniprogram/dev/framework/ability/domain.html  

### 与当前方案的关系

1. **正确做法：** 自托管域名（如 `game.example.com`）放手机网页 + 微信校验文件 → 配业务域名 → web-view 打开该 URL。  
2. **错误做法：** 继续把 `x.qiniu.com` 配成业务域名（平台域无法自行放校验文件；且 XBuilder 非手机主路径）。  
3. 何时值得做：已有非游戏类目企业小程序 + 已有自托管备案域。否则直接投链更优。

## 7. 若上微信小游戏：真实步骤、主体、鸿沟、工期

### 7.1 关键前提

- XBuilder Publish = **桌面/编辑器向 H5**，**不是**微信小游戏包，也**不是**当前手机主路径。  
- 自托管手机网页 = **浏览器 H5**，同样**不是**小游戏包。  
- 官方通用引擎适配面向 WASM + WebGL 产物 + `wx-transformer`：  
  https://developers.weixin.qq.com/minigame/dev/guide/game-engine/common-adaptation  
- spx / XBuilder **无一键「导出微信小游戏」可依赖 → 引擎鸿沟**，需 1024 / 产研评估。

### 7.2 主体与资质

| 项 | 说明 |
| --- | --- |
| 注册 | 选 **游戏** 类目（选定后不可改回普通小程序） |
| 认证 | 企业主体须认证后才能备案 |
| 备案 | 上线前必须小程序备案 |
| 审核 | 软著、自审、隐私协议等以当次清单为准 |
| IAA / IAP | IAA 相对低门槛仍要审；IAP 另需版号等 |
