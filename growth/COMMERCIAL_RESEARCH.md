# 商业调研计划 · 勇敢牛牛（简洁可执行）

> 约束：赛制强制 XBuilder；**无内置广告 / IAP**。  
> 原则：**可持续变现 > 伤留存的虚增长**；不做平台 eCPM、不做虚假用户数调研。  
> 对齐：`MONETIZATION.md`（叙事与投流树）、`MONETIZATION_PLAN.md`（落地）、`METRICS.md`（手记）。

---

## 1. 目标与假设

**目标（本周内）：** 验证哪条赛后路径值得投入，而不是证明「已经能赚钱」。

**「验证」在无 IAP/广告前提下的定义：**

| 路径 | 算验证（通过） | 不算验证 |
|------|----------------|----------|
| P0 案例/课 | ≥3 人明确愿 Remix，或 ≥1 人愿报名 2h 工作坊意向 | 只说「挺有意思」 |
| P1 品牌定制 | ≥1 个部门/业务线有「愿意出皮肤或定制关」意向（口头或书面均可） | 仅点赞、无对接人 |
| P2 迁出接广告 | 本阶段**不做**调研与承诺 | — |
| P3 周边 | 仅作附带观察；非本周主验证 | — |

**核心假设（待证伪）：**

1. 同事/校园用户更愿「玩 + Remix」，而非付费通关。  
2. 对内价值优先：工具样板 + 团建课 / 部门定制关，比对外买量更现实。  
3. Publish 未稳、前 8 秒摩擦大时，谈钱只会伤口碑 → 先修体验再谈变现。

---

## 2. 要回答的 6 个调研问题

1. **Publish 现状：** 链接是否已上线？打开是否稳？手机端跳跃是否可用？  
2. **试玩摩擦：** 前 8 秒是否劝退？死亡文案/结算是否被记住？  
3. **Remix 意愿：** 愿不愿意改编（换皮/改关）？卡点是时间、工具、还是不知道改什么？  
4. **付费形态偏好：** 更接受「团建创作课 / 少儿·校园课 / 部门定制关 / 周边 / 都不」中的哪一类？  
5. **定制赞助意向：** 本部门是否愿为「联名皮 + 二维码落地」出一点预算或人力？开放价感区间（不问死价，只问档：免费互惠 / 小额劳务 / 活动预算）？  
6. **工作坊偏好：** 若做课，更想要「公司团建 2h」还是「少儿/校园」？谁买单？

（可选第 7）传播：挑战卡会不会主动转发？转发给谁？

## 3. 方法与节奏（几天内做完）

| 方法 | 量 | 何时 | 产出 |
|------|----|------|------|
| **内部快访** | **5 人**：设计 ≥1、前端 ≥1、业务/运营 ≥1（其余任意） | Day1 傍晚～Day2 午，共 **≤1.5 天** | 填下方记录表 |
| **桌面研究** | 竞品 3 个：XBuilder 热门 Remix 跑酷/小品；公司内往届 1024 案例；1 个外部少儿编程课大纲 | **半天** | 半页笔记：可抄的结构，非收入数字 |
| **问卷（可选）** | 飞书轻问卷 ≤8 题，群内 **≥15 份** 即够 | 与访谈并行，**1 天收齐** | 偏好占比 |
| **竞品试玩** | 每人玩 10 分钟记「前 8 秒 + 结算记忆点」 | 桌面研究同批 | 对照改关建议 |

**不做：** 平台广告 eCPM 询价、买假量、编造 UV。

## 4. 样本

- **主样本：** 同事（设计 / 前端 / 业务各至少 1）  
- **辅样本：** 校园或实习生 1～2 人（若可得）  
- **创作者样本：** XBuilder 上有过 Publish/Remix 经验的同事或社群 1 人（问工具摩擦）  
- **避开：** 只找已站队的自己人刷好评；至少 1 个「不玩游戏」的业务同学

## 7. 止损规则（什么结果就放弃哪条）

| 结果 | 动作 |
|------|------|
| **通过：** ≥3 愿 Remix **或** ≥1 明确定制/赞助意向 | **推进 P0/P1**（见 `MONETIZATION_PLAN.md`） |
| Remix＜3 且 0 定制意向，但体验吐槽集中在前 8 秒/操作 | **先修自然传播 + 第一关前 8 秒**；本周**不谈钱、不投流** |
| Publish 未稳或试玩普遍打不开 | **停止一切变现话术**；只修 Publish |
| 5 人中 ≥3 选「都不」且反感「还没好玩就谈课」 | **放弃对外卖课叙事（暂缓 P0 对外）**；对内案例叙事可保留 |
| 无人愿定制且无人愿上课 | **P1 暂停**；只保留「创作工具样板」软叙事到比赛结束 |
| 任何「加付费点会更爽」但伤再玩率的建议 | **拒绝**（可持续变现优先于杀留存的增长） |

**明确不调研、不承诺：** 平台内广告分成、虚构 DAU、赛后立刻接激励视频。
