# XBuilder 对齐笔记：植物跑酷 🌻

> XBuilder 已 Publish（标题键 **9** / mapId 6）；本文件记录 mobile-web 对照实现。  
> 美术为 **原创致敬卡通**（`mobile-web/assets/`），**不是**官方植物大战僵尸素材。见 `mobile-web/assets/CREDITS.md`。

## 模式一句话

**植物跑酷**：草坪三道跑酷 + 僵尸造型障碍；捡植物道具；本模式 **🍒 樱桃炸弹 = 当前道连续清障 10 秒**（其他模式炸弹仍为一发清障）。

## 玩法（与 XBuilder 对齐）

| 元素 | 时长 / 节奏 | 效果 |
|------|-------------|------|
| 向日葵 🌻 | ~12s，约每 0.85s | 产阳光 → +1 金币，显示阳光飘字 |
| 豌豆射手 | ~3.4s，约每 0.42s | 沿**当前道**向前射击清僵尸 |
| 加特林 | ~8s，约每 0.18s | 持续扫射当前道；换道时跟随 |
| 坚果 🥜 | ~5s | 护盾：撞僵尸即碎障、不死亡 |
| 樱桃炸弹 🍒 | **10s**（本模式 B / 炸弹键） | **当前道前方连续清障**（非一发） |
| 障碍 | — | `zombie_basic` 致敬僵尸；偶发 tall |

保留：三道换道、跳跃、滑铲、无敌×3、金币线。计分与土路相同：`距离 + 金币×10`。
