## A. 角色动画（必做）

### A1. 跑步循环 — 稳步幅（steady stride）

| 要点 | 做法（XBuilder） | mobile-web 对照 |
|------|------------------|-----------------|
| 步频稳定 | 跑动造型切换跟 **固定节拍**，勿完全跟 `runSpeed` 线性狂飙；速度只做轻量加速 | `runPhase += dt * (1.85 + speed*0.004)` 类稳频 |
| 步幅清晰 | 左右腿交替明显；少上下乱抖 | 压低 bob；腿用更「方」的摆动（非软正弦糊成一团） |
| 前倾 | 轻前倾即可，勿大幅左右摇 | lean 主要来自换道瞬间 |

**验收：** 静止机位看 3 秒，步伐像「一直在跑」，不像「在原地弹」。

### A2. 翻滚 / 滑铲 — 硬切不混合（hard-cut）

| 要点 | 做法 | 勿做 |
|------|------|------|
| 进入 | **立刻**换成 slide/roll 造型（单帧硬切） | 与跑姿 crossfade / 混合骨骼 |
| 持续 | 固定蹲姿/滚姿 0.35～0.5s | 滑动中仍播跑步腿 |
| 退出 | 硬切回跑（可短尘土） | 慢慢 blend 回跑 |

**XBuilder：** 用「换成造型 slide」广播，**不要**用造型渐变；计时器用等待秒数。  
**mobile-web：** 下滑铲已按硬切蹲姿实现（见 CHANGELOG 本条）。

**验收：** 按下滑铲时，上一帧还是跑、下一帧已是铲——肉眼无插值。

## B. 换道（lane）— snap-ish，勿长 lerp

| 项 | 目标 | 备注 |
|----|------|------|
| 手感 | **干脆换道**：大部分位移在前 2～4 帧完成 | Zurich：非平滑长滑 |
| 精调 | 等 **免费三道** 录屏量完「帧数 / 屏宽占比」再锁最终值 | 先 snap-ish 上线 |
| 建议起步 | 逻辑道立刻变；可视位 ≤ ~80–120ms 内到位 | mobile：`LANE_SNAP≈0.78`，`LANE_LERP≈48` |

**验收：** 连点左右，角色不应「飘着追车道」。

## C. 纵深 / 赛道（depth + widen）

对齐 mobile-web **`48b1586`**：

| 参数 | mobile-web | XBuilder 目标 |
|------|------------|---------------|
| 近处路半宽 | `ROAD_HALF_NEAR = 0.50` vw（近端几乎满宽） | 三道贴满下半屏，侧沟很窄 |
| 远处路半宽 | `ROAD_HALF_FAR = 0.13` | 消点仍能看清三轨 |
| 道心 | `LANE_X = [0.18, 0.5, 0.82]` | 更贴轨 |
| 地平线 | `horizonY ≈ 0.14` vh（**上三分之一**消点） | 消点落在画面 **上部 1/3** |
| 近端床 | `nearY ≈ 0.82`；近处路基宽而「外扩」 | **近床外扩感**约占视野下半；flare 明显 |
| 轨槽 | 每道一条暗槽 | 背对镜头三铁轨感 |

**验收：** 截图并排 Subway / mobile-web / XBuilder——近宽、消点偏上、三道清晰。
