关于「勇敢牛牛 · 手机跑酷」

勇敢牛牛，不怕困难。

原创竖屏三道跑酷 · 静态 HTML5 · 可在手机浏览器打开

这是什么

一款轻量竖屏跑酷：选角色（牛牛 / 小鹿 / 小狗），选地图（土路、优美森林、植物跑酷、悬空空间、慢慢跑酷），左右换道、跳跃与滑铲躲障，捡金币、用炸弹或无敌冲撞清障。口号与玩法面向社群活动演示与试玩。

怎么玩

  • 左右滑或 ◀▶：换道
  • 上滑 /「跳」：起跳躲障
  • 下滑：滑铲钻低障
  • 💣 / 植物模式樱桃、🛡️ 无敌：清障或冲撞
  • 撞障时会弹出激励广告示意（本地 2 秒占位，不是 AdSense）

广告与抽奖说明

  • 展示广告位：标题页 / 结算页预留 AdSense 展示位；默认关闭，需发布商自行填入真实 ca-pub-… 后启用。详见仓库 docs/ADSENSE_GITHUB_PAGES.md。
  • 激励视频：撞障流程仍是 mock；真激励需微信小游戏 / TapTap 等 SDK，AdSense ≠ 激励视频。
  • 抽奖 / Top3 红包：活动示意 / 非赌博，本地模拟，非正式发奖。
