# 游戏设计 · 最小可玩闭环（Day1）

> 目标：半天能在 XBuilder/spx 里跑通「跑 → 跳 → 死 → 结算 → 想再来一局」。  
> 品牌句：**勇敢牛牛，天天跑酷** / 死亡句：**勇敢牛牛，不怕困难**

---

## 1. 一句话玩法

牛**自动向前跑**，玩家只负责**跳跃**躲障碍；贴着障碍擦边加「勇敢」层数，**最终分 = 距离分 × 勇敢倍率**；撞上就结算并弹出梗文案。

---

## 2. 操作

| 输入 | 行为 | 备注 |
|------|------|------|
| 无操作 | 角色持续向右移动（或背景向左卷轴） | 速度 Day1 可缓加速，如 `runSpeed` 6→10（见 PARKOUR_REFERENCE） |
| 空格键 | 跳跃 | 与点击二选一或同时支持 |
| 点击 / 触摸舞台 | 跳跃 | 方便手机演示与竖屏录屏 |
| （可选）再按一次 | Day1 **不做**二段跳 | 降低实现与手感风险 |

跳跃参数建议（逻辑值，按舞台单位调；手感迭代见 [`PARKOUR_REFERENCE.md`](PARKOUR_REFERENCE.md)）：

- 起跳初速度 `jumpV = 11`（点按满跳；旧 12 偏飘）  
- 重力 `gravity = 0.95`  
- 卷轴 `runSpeed` 从 **6** 起，约 36s 内可升到 **10**  
- 落地检测：碰到地面或 `y <= groundY`（+y 向上）时清垂直速度；可选土狼/跳跃缓冲  

---

## 3. 障碍

- 类型 Day1 只做 **1 种**：地面矮障（石头/木桩/栏杆），高度约角色身高的 40%～60%，必须跳才过。  
- 生成：按 [`LEVEL_1.md`](LEVEL_1.md) 时间轴摆好，或「每 N 帧在右侧克隆一个」。  
- 碰撞：障碍的「危险盒」略小于造型，避免「看起来没撞却死」；**擦边带**见下一节。

---

## 4. 分数：距离分

- 变量：`distance`（整数）  
- 规则：每帧（或每 0.1 秒）`distance += 1`（或 `+= runSpeed` 再取整）  
- UI：左上角显示 `距离：{distance}`  
- 死亡后距离**冻结**，不再增加  

---

## 5. 勇敢倍率（核心差异点）

### 5.1 什么叫「擦边」

障碍碰撞盒外扩一圈为 **勇敢带（近距区）**，例如危险盒左右各 +8～12px：

- 进入勇敢带且**未**进入危险盒 → 触发一次「擦边成功」  
- 同一障碍只触发 **1 次**（用障碍实例的 `alreadyBrave` 标记）

### 5.2 变量

| 变量 | 含义 | 初值 |
|------|------|------|
| `braveStacks` | 勇敢层数 | 0 |
| `braveMultiplier` | 倍率 | 1 |
| `score` | 结算分 | 0 |

推荐公式（简单好讲）：

```
braveMultiplier = 1 + braveStacks
score = distance * braveMultiplier
```

可选强化（评委更好懂）：每次擦边播放「勇敢 +1！」飘字，并短闪角色描边。

### 5.3 上限

Day1 建议 `braveStacks` 上限 **9**（倍率最高 10），避免数字爆炸；UI 可显示 `勇敢 ×{braveMultiplier}`。

---

## 6. 死亡与文案

**触发：** 角色危险盒与障碍危险盒相交。

**立即：**

1. 停止跑、停刷距离  
2. 播死亡姿势 / 停一帧  
3. 弹出结算面板（见下节）  
4. 主文案固定：  
   - 标题：**勇敢牛牛，不怕困难**  
   - 副文：`再来一局，更勇敢一点！`  
5. （加分项）若本局 `braveStacks >= 1`，加一行：`本局最勇：擦边 {braveStacks} 次`

**不要**在 Day1 做复杂复活币；最多一个「再玩」按钮 = 重置变量并回到起点。

---

## 7. 结算字段（面板上必须有）

| 字段 | 来源 | 展示示例 |
|------|------|----------|
| 距离 | `distance` | 距离 1280 |
| 勇敢层数 | `braveStacks` | 勇敢 +3 |
| 倍率 | `braveMultiplier` | ×4 |
| 最终得分 | `score` | 得分 5120 |
| 梗句 | 常量 | 勇敢牛牛，不怕困难 |
| 挑战引导 | 文案 | 复制挑战卡，去群里踢馆 → |

挑战卡模板见 [`../growth/CHALLENGE_CARD.md`](../growth/CHALLENGE_CARD.md)。  
Day1 可用「显示变量 + 说一段话」模拟面板；有时间再做造型拼 UI。

---

## 8. 一局流程（状态机）

```
标题页（点开始）
  → 奔跑中（跑+跳+刷分+检测擦边/碰撞）
    → 结算页（显示字段 + 再玩 / 复制文案提示）
      → 重置 → 奔跑中
```

可选极简标题：大字「勇敢牛牛，天天跑酷」+「空格或点击开始」。

---

## 9. Day1 明确不做

- 二段跳、滑铲、道具商店真扣费  
- 联网排行榜（改用群内挑战卡人工比）  
- 多种敌人 AI  
- 广告 SDK / IAP（平台侧不作为依赖；叙事放 `growth/MONETIZATION.md`）
