隐私政策

最后更新：2026-10-25 · 适用于 GitHub Pages 上的「勇敢牛牛 · 手机跑酷」静态页

本页面说明我们如何处理与本游戏相关的信息。本游戏为静态网页（当前托管于 GitHub Pages），没有自建账号服务器；多数数据只保存在你的设备本地。

1. 我们收集什么

  • 本机游戏数据：排行榜记录、演示登录昵称/头像、抽奖示意状态等，保存在浏览器 localStorage，一般不会上传到我们的服务器（当前亦无自建后端）。
  • 技术日志：托管方（如 GitHub Pages）可能记录常规访问日志（IP、User-Agent、请求路径等），由托管方按其政策处理。
  • 广告相关（可选，默认关闭）：若你日后启用 Google AdSense 展示广告，Google 可能使用 Cookie 或类似技术用于展示广告、衡量效果与防欺诈。未配置发布商 ID、未打开启用开关前，本站不会加载 AdSense 脚本。

2. Cookie 与类似技术

游戏本身主要使用 localStorage 存本地进度与示意活动状态。启用 AdSense 后，第三方（Google）可能设置 Cookie。欧洲经济区 / 英国等地区用户在启用广告前，应先完成适用的同意流程；开发者接入真实广告时需自行补齐同意条。

3. 我们如何使用信息

  • 提供跑酷玩法、本机排行与活动示意界面；
  • （启用后）展示广告并可能用于广告效果统计；
  • 改进页面可用性与排查错误（依赖托管方日志）。

4. 第三方服务

  • GitHub Pages：静态托管。
  • Google AdSense（可选）：仅在配置真实 ca-pub-… 且打开 window.__RB_ADSENSE.enabled 后加载。详见 Google 的广告与隐私说明。
  • 撞障「激励视频」当前为本地占位，不是 AdSense，也不上传观看数据。

5. 抽奖与奖金说明

页面上的 Top3 红包与趣味抽奖为活动示意 / 非赌博，本地模拟，不构成真实支付或博彩。正式发放若开展，将另有规则与合规说明。

6. 儿童

本游戏面向一般休闲娱乐。若你未满当地数字服务法定年龄，请在监护人指导下使用；启用广告后请遵守 AdSense 关于儿童相关内容的政策。

7. 你的选择

  • 可在浏览器设置中清除本站数据 / Cookie；
  • 可通过浏览器控制广告个性化（例如 Google 广告设置）；
  • 不启用 AdSense 时，本站不加载广告脚本。
