# 第一关 · 障碍节奏表（Day1）

> 设计原则：**前 30 秒好懂、好录屏；30 秒后加压**，逼出擦边与翻车名场面。  
> 坐标系（逻辑描述）：地面为 `groundY`；障碍从右侧 `spawnX` 进入，向左相对运动（或牛向右跑）。  
> 时间轴以「开局起跑 = 0s」计；速度假设牛相对卷轴约 **8 单位/帧** 量级——下表用**时间间隔**表达，在 XBuilder 里用「等待秒数」或「当 distance 达到」触发均可。

---

## 1. 分段目标

| 时段 | 目标手感 | 障碍密度 | 擦边教学 |
|------|----------|----------|----------|
| 0～8s | 安全感、学会跳 | 极疏 | 无或 1 次宽擦边 |
| 8～20s | 节奏感 | 中等、均匀 | 鼓励擦边 |
| 20～30s | 「我可以」 | 中高、出现双连 | 必须算节奏 |
| 30～45s | 加压名场面 | 高、变化间隔 | 高勇敢或高死亡 |
| 45s+ | 可选无尽 | 随机或循环 B 段 | 为竖屏「最惨死法」供素材 |

Day1 **主路径做到 45s 内必遇结算**即可（障碍够密或速度略加快）。

## 3. 逻辑坐标与间隔（实现提示）

不必用真实像素，按 spx/Scratch 思维：

```
常量:
  groundY ≈ 角色站立 y
  spawnX  = 舞台右缘外一点（如 x = 240 或 280）
  gapEasy = 相当于 3.0～3.5s 的水平间距
  gapHard = 相当于 1.2～2.0s 的水平间距

若用「克隆+移动」:
  障碍.x 每帧 -= scrollSpeed
  当 障碍.x < 左缘外: 删除克隆体

若用「distance 触发」:
  当 distance = D1 时克隆 #1
  当 distance = D2 时克隆 #2
  …（把上表秒数 × 每秒距离增量 换成 D）
```

**擦边带：** 危险碰撞左右收缩 2～4 单位；勇敢检测用放大盒；同一克隆体 `alreadyBrave=false`，触发后置 true。

---

## 4. 演示专用「安播路线」

给评委演示时建议：

1. 0～20s **正常玩**，故意在 #3 或 #6 擦边 1～2 次  
2. 在 #9～#10 双连再擦一次，喊「勇敢 +1」  
3. 可在 #15 **故意撞死**，露出结算与梗句（比硬撑到无尽更可控）  

竖屏「最勇擦边」素材优先录 #10；「最惨死法」优先录 #15。

---

## 5. 调参口诀（手感不对时）

- 总是第一下就死 → 把 #1～#3 再疏 0.5s，或降低 `scrollSpeed`  
- 从没人擦边 → 加宽勇敢带，或 #3/#6 危险盒再窄一点  
- 录屏太长才死 → 从 #11 起全面 -0.3s 间隔  
- 分数都一样 → 检查是否同一障碍重复触发勇敢（缺 `alreadyBrave`）  

---

## 6. 验收

- [ ] 前 30s 新手不看攻略能玩懂  
- [ ] 30s 后 15s 内大多数人会结算  
- [ ] 至少 1 处双连、1 处三连压迫  
- [ ] 有 2 个「名场面点」可供短视频分镜使用
