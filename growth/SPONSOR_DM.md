# 品牌定制关 · 赞助私聊（可复制）

> P1。发给业务线 / 品牌 / 招聘 / 校园运营对接人。  
> 替换 `{对方部门}` `{Publish}` `{你的名字}`。不报价死数；先问档位。

---

## 飞书私聊 · 标准版（推荐）

```
Hi，我是 {你的名字}，1024 做了个 XBuilder 小游戏「勇敢牛牛，天天跑酷」。

想跟你们 {对方部门} 试一枪定制关，不塞广告、不接 IAP：
· 我们出：一关可玩跑酷 + 扫码二维码 + 结算页落地链
· 你们出：logo/吉祥物皮 + 一句 slogan（可落到活动/招聘/报名页）
· 节奏：有素材的话，比赛后约 1 周可出 Demo 关给你们内测

试玩原作：{Publish}
（未 Publish 可写：演示后补链接）

先不谈死价，想确认一档意向就行：
A 免费互惠（你们出皮，我们挂落地）
B 小额劳务（设计/加班费量级）
C 活动预算里单列一笔

方便的话回 A/B/C，或约 15 分钟口头对一下落地页目标。谢谢！
```

---

## 飞书私聊 · 更短版

```
「勇敢牛牛」想给 {对方部门} 做一关定制皮：员工扫码就能玩，结算落到你们活动/招聘页。
我们出关+码，你们出皮+slogan；游戏内不塞广告。
原作：{Publish}
意向档：互惠 / 小额劳务 / 活动预算？回一个就行。
```

---

## 跟进（对方回了 A/B/C 后）

```
收到，按 {A/B/C} 走。
请丢我：① 主视觉/吉祥物（png）② slogan 一句 ③ 希望结算跳转的链接。
我们出一版 Demo 关内测包，确认后再定是否正式挂码。
```

---

## 使用注意

1. 未 Publish 不发「已可扫码」话术；可先发「比赛演示后补链」。  
2. 不问死价；档位对齐 `COMMERCIAL_RESEARCH.md`。  
3. 成功：对方回档 + 给对接人；失败：礼貌结束，不追发广告承诺。
